# План следующих релизов

## v1.1.0 — административный удалённый доступ

По решению владельца проекта удалённый доступ начинается со второго релиза.
NetBird — кандидат; выбор реализации будет сделан после отдельной проверки на
OpenWrt и оценки ресурсов, маршрутов, DNS и способа регистрации устройств.

План работы:

1. Опциональное подключение устройства администратором, выключенное по умолчанию.
2. Учёт и отзыв устройств; разделение доступа администратора и обычного клиента.
3. Проверка совместимости с туннелем, LAN/uplink, DNS, watchdog и перезагрузкой.
4. Безопасное отключение и удаление агента с сохранением обычного интернета.
5. Аппаратные испытания и описание подключения перед выпуском.

Ключи регистрации, пользовательские пароли и общие секреты не включаются в APK.
Этот документ фиксирует направление; агент удалённого доступа в v1.0.0 не добавлен.
