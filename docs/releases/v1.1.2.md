# xtlsproVPN v1.1.2 (r2)

Исправлено обновление подписки на роутерах с 256 МБ RAM при работающем NetBird.

- Для поддерживаемых конфигураций изменённые узлы проверяются последовательно отдельными небольшими процессами Xray. Минимальный порог доступной RAM — 32 МиБ вместо 96 МиБ.
- Сохранены предварительные проверки HTTPS и DNS, защита рабочей конфигурации и откат после неудачного применения. Для конфигураций, требующих полной проверки, сохраняется порог 96 МиБ.
- Временные конфиги имеют расширение .json, необходимое Xray.
- Сообщения об ошибках объясняют нехватку памяти; интерфейс снимает состояние ожидания после завершения или замены операции.

Проверено на Dimarouternew: при 50 560 КиБ доступной RAM подписка применена, RSS проверочного Xray составил 25 560 КиБ. HTTPS вернул 204; DNS UDP/TCP сохранил TTL 60. NetBird остался подключённым с прежним PID. Диагностика LuCI — 26/26, ошибок 0. На устройстве проверен r1 с тем же исправлением расширения файла, которое включено в r2.

Пакет: xtlsprovpn-1.1.2-r2.apk. OpenWrt 25.12.5, aarch64. Ядро Xray и NetBird управляются отдельно. Настройки при обновлении сохраняются.

Обновление доступно через LuCI: Services → xtlsproVPN → обновление приложения. Перед установкой сверяется SHA-256. В релиз включены APK, SHA256SUMS и update.json.
