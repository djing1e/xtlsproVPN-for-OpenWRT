# xtlsproVPN 1.4.8-r1

- При отказе прокси после трёх неудачных проверок роутер переходит на прямой интернет: снимает перехват LAN и возвращает прежний DNS. Неудачная прямая контрольная проверка больше не оставляет клиентов в неработающем туннеле.
- Xray остаётся доступен для фоновых проверок. Возврат прокси требует двух успешных HTTPS-проверок, проверки DNS по UDP и TCP и повторной проверки после включения перехвата. Ручная остановка запрещает автоматическое включение.
- Исправлено продление и обновление истёкшей подписки из прямого режима. Новая конфигурация проверяется независимо от старого неработающего прокси. При ошибке откат сохраняет прямой режим.
- Обновлены подписи состояний и операций. Дашборд, мониторинг и диагностика используют новые пути модулей, чтобы браузер загрузил актуальный интерфейс.
- Исправлено ложное сообщение бота об ошибке обновления при штатной миграции DNS/NetBird. Допускается только проверенная миграция dnsmasq; остальные настройки продолжают проверяться. Бот сообщает этап неудачной проверки. Обработчик роутера входит в APK; серверная часть входит в отдельный архив бота.

На HOME подтверждены смоделированный отказ проверки, реальное отключение подписки из панели, истечение подписки, её продление и обновление, а также автоматический возврат прокси. В прямом режиме подтверждены рабочие DNS и HTTPS. В смоделированном тесте PID Xray сохранился.

Сохранены настройки подписки, маршрутизации, ZRAM и NetBird. Ядро Xray и NetBird обновляются отдельно. Для новых сообщений серверной части бота требуется отдельно обновить сервер бота. После установки обновите страницу LuCI.

Поддерживаемые платформы APK: OpenWrt 25.12.5/25.12.6, aarch64. Известное ограничение применения DNS при остановленном Xray не изменено.
