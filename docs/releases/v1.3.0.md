# xtlsproVPN v1.3.0 (r3)

Восстановление административного доступа: guard NetBird и аварийный обратный SSH через существующий сервер.

- Guard подтверждает отказ перед start/restart NetBird, ждёт восстановления uplink и сервера управления, учитывает ручное отключение и ошибки авторизации. Не более трёх попыток восстановления в час. Регистрация сохраняется.
- В панели NetBird появился аварийный SSH. Используется встроенный Dropbear: дополнительный тяжёлый агент не нужен. Резерв выключен по умолчанию; сервер, порты и ключи настраиваются отдельно для каждого роутера.
- После пяти минут отказа NetBird резерв открывается автоматически. После восстановления остаётся ещё десять минут. Кнопки позволяют открыть резерв либо приостановить его на 30 минут.
- Повторные подключения выполняются с паузами 30/60/120/300 секунд. Входящий порт на сервере слушает только loopback. Ключ сервера закреплён; приватный ключ роутера не возвращается через RPC.
- Исправлено чтение known_hosts клиентом в окружении procd. Добавлена совместимость аварийного SSH с автозапуском существующего NetBird через netbird-wrapper.

На LAB проверены восстановление NetBird после завершения и зависания процесса, ожидание uplink и повторное подключение без setup key. На HOME проверены SSH-вход через резервную службу, ручное закрытие/открытие, перезапуск клиента, автоматическое открытие при отказе NetBird и закрытие после восстановления. RSS SSH-клиента в тестах — около 0,9 МиБ.

Ограничения: сервер резерва задаётся IPv4-адресом; перехват OUTPUT пока не поддерживается. Состояние процесса/TCP не подтверждает полноценный административный вход. Guard управляет NetBird, включённым через приложение; поддержка netbird-wrapper в резерве не передаёт существующую установку под управление guard. Отдельный Telegram-бот в эту версию не входит.

Пакет: **xtlsprovpn-1.3.0-r3.apk**, OpenWrt 25.12.5 / aarch64. Xray и NetBird обновляются отдельно. Для обновления приложения через LuCI нужны APK, SHA256SUMS и update.json из одного проверенного артефакта.

Подготовка релиза: перед публикацией проверить итоговый APK на HOME, сохранение ключей и настроек, запуск после перезагрузки. Публиковать тот же проверенный APK, без пересборки.
