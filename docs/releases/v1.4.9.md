# xtlsproVPN 1.4.9-r1

В APK включены исправления, подтверждённые на роутерах после 1.4.8.

- **Настройки LuCI:** исправлена ошибка `factory yields invalid constructor`.
  Вкладки, включая «Память» и «Административный доступ», загружаются корректно.
  Основные страницы и общий модуль используют новые пути JavaScript, чтобы после
  обновления браузер не загружал старую реализацию из кэша.
- **Стабильный автовыбор:** проверка текущего соединения отделена от фоновых замеров
  всех локаций. По умолчанию соединение проверяется раз в 10 секунд; прежний
  интервал фоновых замеров сохраняется. Две последовательные ошибки запускают
  поиск резервной локации со свежей HTTPS-проверкой. Небольшие изменения пинга
  не переключают работающий маршрут: нужны преимущество одновременно 20% и 50 мс,
  три разных замера обеих нод и пауза 5 минут после последней смены. При отказе
  текущей ноды эта пауза не применяется. Интервалы являются расписанием проверок:
  фактическое время обнаружения также включает сетевые таймауты и работу монитора.
- **Fail-open:** если резерв не проходит проверку, сохраняется автоматический
  переход на прямой интернет. Возврат прокси требует успешных проверок HTTPS и
  DNS по UDP/TCP. Ручной режим не меняет выбранную ноду автоматически.
- **FinalMask:** поддержан параметр `fm` в VLESS-ссылках и `finalmask` в JSON для
  RAW/REALITY и XHTTP. Маска сохраняется до итоговой конфигурации Xray. Узлы с
  одинаковыми адресом и UUID, но разными масками больше не теряются как дубликаты.
  Конкретная маска должна поддерживаться установленным ядром Xray.
- При обновлении APK перезапускается только уже работавший монитор, чтобы он
  получил новый цикл проверки. Xray не перезапускается установщиком; намеренно
  остановленный монитор не включается.

На LAB подтверждены загрузка настроек, аварийная смена ноды без перезапуска Xray,
удержание рабочего маршрута после возврата прежней ноды и переход на доступную
локацию после отказа. В последнем тесте watchdog зафиксировал недоступность
12 секунд; это результат конкретного теста, а не гарантированный срок для любой
сети. На роутере с FinalMask подтверждены появление локаций и рабочие подключения.

Отдельный серверный архив бота включает последовательное массовое обновление APK,
предварительный подсчёт актуальных/офлайн-устройств, проверки результата и одну
редактируемую карточку прогресса. Серверная часть устанавливается отдельно на VPS.
Обновление APK на роутере само по себе сервер бота не меняет.

**Платформа:** OpenWrt 25.12.5/25.12.6, aarch64. Это пакет приложения, не прошивка.
Настройки подписки, LAN/WAN, DNS, маршрутизации, ZRAM, NetBird и аварийного доступа
сохраняются. Ядро Xray и NetBird обновляются отдельно. Дополнительные скрипты фиксов
1.4.8 после установки 1.4.9 не требуются.

Для установленного приложения: LuCI → xtlsproVPN → «Обновление приложения» →
«Проверить обновление» → «Установить обновление». После завершения обновите страницу.
Для проверки FinalMask обновите подписку, чтобы узлы разобрались новым импортёром.
