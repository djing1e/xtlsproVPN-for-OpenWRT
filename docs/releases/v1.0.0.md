# xtlsproVPN v1.0.0

Первый релиз пакета xtlsproVPN для OpenWrt. Публикуется проверенный на тестовом
роутере APK `xtlsprovpn-1.0.0-r5.apk`; номер r5 — ревизия пакета первого релиза.

## Возможности

- Подписки VLESS / REALITY / XHTTP, ручной выбор узла и автовыбор.
- Прозрачный перехват IPv4 TCP/UDP и DNS клиентов, пользовательские правила
  PROXY / DIRECT / BLOCK, профиль раздельной маршрутизации.
- Настройки DNS, DoH/DoT, фиксированный TTL, управление QUIC.
- Watchdog, диагностика, обновления подписки и маршрутизации по расписанию.
- Установка ядра из интерфейса, проверка совместимости, обновление, ручной и
  автоматический откат при неуспешной проверке после переключения.
- Сохранение подписки и конфигурации при ошибках обновления; восстановление
  незавершённого применения подписки после отключения питания.
- Автоматическая защита от ICMP redirects для схемы с общим LAN/uplink.

## Проверенная платформа

Cudy WR3000U v1, OpenWrt 25.12.5, mediatek/filogic, aarch64. Основные проверки
проводились с Xray 26.7.28; проверены установка 26.10.10 и возврат на 26.7.28.
Ядро, базы маршрутизации и пользовательская подписка в APK не входят.

На LAB проверены загрузка после потери питания, восстановление прерванного
обновления подписки, watchdog, DNS UDP/TCP с TTL 60, доменные правила на клиенте,
обновление и откат ядра, фактический запуск обновлений через cron.
Полный протокол и границы проверки: `docs/lab-validation-2026-10-16.md`.

IPv6-перехват в этом выпуске не реализован. Проверка других моделей, отдельных
IP/CIDR-правил, DoT и всех дополнительных настроек DNS не завершена в этой серии
аппаратных тестов. Журнал восстановления защищает применение подписки, а не
установку APK или замену бинарника ядра при отключении питания.

## Установка

Скачайте APK и `SHA256SUMS` из файлов этого релиза и перенесите оба файла в `/tmp`:

```sh
clear
cd /tmp
sha256sum -c SHA256SUMS
apk update
apk add --allow-untrusted ./xtlsprovpn-1.0.0-r5.apk
```

`--allow-untrusted` необходим для этого локального APK: постоянная доверенная
подпись репозитория пакетов в первом релизе не предоставляется. SHA-256 APK:

```text
cdf493ff09f95e010d86f07d68ff40f8f2b38780103ef130c8f4ea1a8c6308e0
```

После установки откройте Services → xtlsproVPN: установите ядро, укажите URL
подписки, обновите подписку и профиль маршрутизации, затем запустите прокси.
Для подключения к интернету через LAN выберите `lan` как наблюдаемый интерфейс
watchdog. Flow offloading перед использованием перехвата должен быть выключен.
Существующая установка **этого же r5** уже совпадает с релизным пакетом;
повторная установка для перехода из проверенной r5 не требуется.
