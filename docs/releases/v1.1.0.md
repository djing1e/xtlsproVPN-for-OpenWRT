# xtlsproVPN v1.1.0

Второй стабильный релиз: пакет **1.1.0-r5** для **OpenWrt 25.12.5 / aarch64**.
Публикуется исходный APK из Actions 39032775495, проверенный на роутере.

Добавлено:

- NetBird для self-hosted сервера: установка по запросу, подключение через setup key,
  статус, автозапуск и восстановление после перезагрузки.
- SSH и LuCI через адрес NetBird. DNS и клиентские/серверные маршруты NetBird отключены.
- Исправлена передача setup key через RPC, обработка ошибок и повторного подключения.
- Облегчённая предварительная проверка DNS через работающий транспорт узла:
  DoH через прокси проверен на роутере с 256 МБ RAM.

Проверено на Cudy WR3000U v1 и WR3000S v1 (OpenWrt U-Boot layout),
OpenWrt 25.12.5 / mediatek/filogic. На WR3000S проверены NetBird, доступ SSH/LuCI,
автозапуск после перезагрузки, HTTPS через прокси и DNS UDP/TCP с TTL 60.
На WR3000S использован ZRAM 128 МиБ; приложение не включает его автоматически.

## Установка

Чистая установка, если пакет ещё не установлен:

```sh
wget -O /tmp/xtls-install.sh https://raw.githubusercontent.com/djing1e/xtlsproVPN-for-OpenWRT/main/install.sh && sh /tmp/xtls-install.sh
```

Обновление существующей установки с сохранением конфигурации:

```sh
wget -O /tmp/xtls-update.sh https://raw.githubusercontent.com/djing1e/xtlsproVPN-for-OpenWRT/main/update.sh && sh /tmp/xtls-update.sh
```

Уже установленный **1.1.0-r5** соответствует этому релизу: переустановка не нужна.
Установщики проверяют платформу и SHA-256. APK устанавливается с
`--allow-untrusted`; ключ подписанного APK-репозитория пока не распространяется.
При обновлении возможен краткий перезапуск прокси.

NetBird — отдельный необязательный пакет из репозитория OpenWrt. Ядро Xray также
устанавливается отдельно. Проверенная базовая версия Xray — 26.7.28.
Настройки LAN/WAN и DHCP установщик не изменяет.

## Ограничения

IPv6-перехват и автоматическое обновление версии NetBird не реализованы.
Проверка нагрузки с десятью активными устройствами и длительный прогон на HOME
ещё не завершены. Наличие подключения NetBird требует рабочего uplink.
Предупреждения firewall4 об опции `xtlspro_managed` относятся к служебной метке;
доступ SSH/LuCI через NetBird проверен, очистка предупреждений планируется отдельно.

Обновление APK через UI разрабатывается следующей сборкой и в этот проверенный
APK не добавлялось. Исходники NetBird и документация: [руководство](../../docs/netbird-admin.md).
