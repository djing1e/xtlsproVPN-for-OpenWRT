# xtlsproVPN 1.4.3-r1

- Подписка загружается напрямую, независимо от настроек прокси в окружении; автоматический переход на SOCKS удалён. Проверка HTTPS сохраняется.
- Недоступная дополнительная нода больше не отменяет применение всей подписки при наличии проверенного рабочего пути. В автовыборе проверяются следующие кандидаты; в ручном режиме обязателен выбранный узел.
- При отсутствии рабочего пути сохраняются предыдущие каталог и конфигурация. Проверки структуры Xray, nftables, памяти и транзакционный откат сохранены.
- Проверки запуска и watchdog закреплены за основным балансировщиком через отдельный локальный SOCKS 11499. Пользовательское правило DIRECT не может дать ложное подтверждение работы прокси.
- Сохранены исправления бота и автоматическое определение интерфейса LAN из 1.4.2.

OpenWrt 25.12.5/25.12.6, aarch64. Обновление APK сохраняет настройки. Выпуск не устанавливается на роутеры или VPS автоматически. Сервер бота не требует обновления для этих изменений.

Известное ограничение: применение DNS через интерфейс при остановленном прокси остаётся отдельной задачей. Выпуск не исправляет недоступность внешних DNS или ошибки настройки сервера подписки.
