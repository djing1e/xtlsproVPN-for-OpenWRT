# xtlsproVPN v1.1.1 — пакет 1.1.1-r2

Обновление приложения через LuCI: **xtlsproVPN → Обновление приложения**.
Релиз содержит APK, SHA256SUMS и манифест update.json для OpenWrt 25.12.5/aarch64.

- Проверка стабильных релизов и установка выбранной версии по кнопке.
- Сверка платформы, размера и SHA-256, запрет понижения версии.
- Приватная резервная копия конфигурации перед установкой.
- Отдельный установщик procd, продолжающий работу при перезапуске LuCI/rpcd.
- Проверки версии, ядра, HTTPS, DNS, перехвата LAN и ранее подключённого NetBird.
- В r2 исправлено определение установленной версии через `apk info -v -e`.

Xray, подписка и NetBird не заменяются. Во время установки возможен перерыв
соединения. Автоматический откат APK не реализован; ошибки и прерывания
показываются в статусе, резервная копия настроек сохраняется.

Сборка и автоматические тесты проверены в Actions. На HOME проверены ручная
установка r1, проверка каталога, исправление определения версии, HTTPS и NetBird.
Первая реальная установка r1 → r2 через UI проверяется этим выпуском;
восстановление после отключения питания во время установки APK ещё не проверено.

Если установлена 1.1.1-r1 с исправлением определения версии, нажмите
«Проверить обновление» и установите 1.1.1-r2. Для 1.1.0-r5 требуется первоначальная
ручная установка новой версии: там вкладки обновления приложения ещё нет.

Подробности: [механизм обновления](https://github.com/djing1e/xtlsproVPN-for-OpenWRT/blob/49389264f520f1f33cd99038dfd5d450342c662d/docs/package-updates.md).
