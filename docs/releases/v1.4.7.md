# xtlsproVPN 1.4.7-r1

- Исправлено подключение вкладки Настройки → Память. В 1.4.6 панель ZRAM и серверная часть были установлены, но вкладка добавилась в устаревшую страницу settings_052, тогда как меню открывало settings_transfer2.
- Меню теперь открывает единственную действующую страницу settings_memory147. Старые имена страниц оставлены как перенаправляющие модули, чтобы не поддерживать расходящиеся копии настроек.
- Сохранена вкладка «Административный доступ» с NetBird. Проверяется рендер страницы, которую действительно открывает menu.d: восемь вкладок, подключение Памяти и NetBird, переход по #memory/#dns, клавиатура и изоляция ошибок RPC.
- Изменений работающего ZRAM, Xray и NetBird в этом исправлении нет. Ручные 128 МиБ/lzo читаются из существующих настроек. После обновления перезагрузите страницу LuCI через Ctrl+F5.

Сохранены функции ZRAM из 1.4.6 и исправления DNS/NetBird из предыдущих выпусков. Сервер бота обновлять не требуется.

Новая UI проверена тестами действующего маршрута; применение на физическом роутере остаётся аппаратной проверкой после обновления APK. Известное ограничение DNS при остановленном Xray не изменено.
