# xtlsproVPN 1.4.2-r1

- Исправлена версия приложения в карточке Telegram-бота: читается установленная версия APK.
- Исправлена ложная ошибка «Конфигурация изменилась» при регистрации роутера с неявным параметром RICH.
- В режиме «Автоматически» интерфейс источника определяется по текущему LAN OpenWrt; результат виден в «DNS и сеть». Ручной выбор имеет приоритет.
- Включены ранее подготовленные исправления интерфейса бота, доступности роутеров и RICH-сообщений.
- Манифест обновления поддерживает OpenWrt 25.12.5 и 25.12.6, aarch64. Ядро Xray устанавливается отдельно.

Обновление APK сохраняет настройки. Сервер бота обновляется отдельно из xtls-router-bot-1.4.2.tar.gz штатным механизмом upgrade-release.sh с резервной копией. Выпуск не обновляет устройства или VPS автоматически. Автовыбор локаций не изменён.
