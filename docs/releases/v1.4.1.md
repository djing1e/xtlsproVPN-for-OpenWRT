# xtlsproVPN v1.4.1 (r1)

Накопительный выпуск для установки на клиентские роутеры. Содержит приложение
OpenWrt **1.4.1-r1** и отдельный серверный комплект бота **1.4.1**.
Совместимость APK: OpenWrt 25.12.5 / aarch64. Бинарные файлы Xray и NetBird
устанавливаются и обновляются отдельно.

## На роутере

- Актуальный комплект ограниченных SSH-обработчиков бота уже внутри APK:
  фактический HWID Remnawave, карточка подписки без передачи её URL,
  локации, диагностика, административные задания и проверки обновлений.
- Автоматическое обновление обработчиков на зарегистрированном роутере
  сохраняет UUID, профиль, ключи и клиентские привязки на VPS.
- Guard NetBird поддерживает штатную службу и явно выбранный
  `netbird-wrapper`. Для уже работающего внешнего wrapper доступна команда
  `xray-lab-bot guard-wrapper`: проверяет регистрацию, сохраняет конфигурацию
  и включает Guard без переподключения NetBird. Она не запускается автоматически
  при установке и не отменяет осознанное отключение NetBird пользователем.
- `xray-lab-bot join PROFILE_CODE` использует комплект из APK. Современный
  обработчик HWID не заменяется старой сетевой заплаткой; для 1.4.0 сохранён
  проверяемый по SHA256 совместимый bootstrap.
- Аварийный обратный SSH с проверкой ключа VPS, ожиданием восстановления,
  ручным открытием, паузой, повторными попытками и закрытием при здоровом NetBird.

## На VPS бота

- «Мои роутеры»: 10 устройств на странице, короткие имена, поиск по имени,
  полному/частичному HWID и номеру подписки. Полный HWID остаётся в карточке.
  Поиск использует кэш, соблюдает клиентские права и не опрашивает весь парк по SSH.
- Кнопки выдачи/отзыва доступа с уведомлениями, защита повторных нажатий,
  административное добавление роутеров и резервное копирование.
- Подключение через NetBird и переход на ограниченный аварийный SSH.
  Повторная регистрация сохраняет существующую запись и клиентские доступы.
- Ежедневно в **12:00 Europe/Moscow** создаётся и проверяется зашифрованный
  архив, затем отправляется только администратору. На VPS остаются последние
  14 архивов; Telegram сохраняет историю отправленных файлов.
- Повтор доставки при сетевой ошибке использует ожидающий архив. Подтверждённая
  доставка за день повторно не отправляется. При потере подтверждения Telegram
  после успешной загрузки возможен дубликат.
- Своя парольная фраза со скрытым двойным вводом и проверкой нового архива
  перед заменой секрета. Восстановление через `--ask-passphrase` не требует
  исходного файла `backup.key`. Старые архивы требуют своего прежнего ключа.
- Исправлены права каталогов после восстановления с `umask 077`.
  Восстановленная копия оставляет бот, operator jobs и отправку архивов выключенными.

## Файлы выпуска

- `xtlsprovpn-1.4.1-r1.apk` — приложение для роутера.
- `xtls-router-bot-1.4.1.tar.gz` — публичный серверный код и инструкции;
  внутри собственный SHA256SUMS. Токена, паролей, клиентской базы и ключей нет.
- `update.json` — метаданные безопасного обновления APK через LuCI.
- `SHA256SUMS` — контрольные суммы APK и серверного архива.

## Обновление

На существующем VPS бота распакуйте проверенный серверный архив и выполните
`sh xtls-router-bot-1.4.1/server/upgrade-release.sh` от root. Установщики сохраняют
токен, конфигурацию, SSH-ключ, known_hosts, пароль резервных копий и привязки.
Краткий перезапуск службы бота применяется для загрузки нового кода. Время
ежедневных копий — 12:00 МСК. Команда не спрашивает и не меняет парольную фразу.

На роутере установите APK через LuCI либо `apk add --allow-untrusted` после
проверки SHA256. Обновление сохраняет существующие UCI-конфигурации, идентичность
и ключи. Новому устройству требуется отдельное подключение к боту; одно обновление
APK не выдаёт Telegram-доступ и не переносит регистрацию с другого роутера.

Для уже обновлённого HOME с внешним wrapper повторно включать Guard не требуется:
настройка службы сохраняется. На других legacy-устройствах включайте его явно.

## Проверки

Автоматические тесты охватывают команды SSH, клиентские права, каталог на 500
устройств, регистрацию, обновление обработчиков, Guard, аварийный канал,
шифрование/ротацию/доставку, восстановление и парольные фразы. APK собирается
официальным OpenWrt SDK с проверкой SHA256; релиз публикует ровно проверенные
артефакты и повторно скачивает их для сравнения.

На LAB и HOME проверены компоненты этой версии: Telegram-доступ и смена локаций,
возврат между NetBird и аварийным каналом, сохранение идентичности, Guard wrapper,
восстановление бота на отдельном Debian VPS, восстановление аварийного пользователя
LAB и возврат туннеля на исходный VPS. Реальная ежедневная отправка и смена
парольной фразы также проверены. Новый APK 1.4.1 требует обычной проверки после
обновления первого роутера; физическая установка именно этого файла не подменяется
результатами тестов предыдущего APK.
