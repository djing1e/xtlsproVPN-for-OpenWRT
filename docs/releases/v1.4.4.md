# xtlsproVPN 1.4.4-r1

- Исправлено применение DNS с перезаписью TTL при наличии внешнего сервера dnsmasq. Пока работает прозрачный прокси, конкурирующие глобальные DNS временно исключаются; доменные правила сохраняются. При остановке восстанавливаются исходные значения, если администратор не изменил их вручную.
- Настройка DNS сетевого интерфейса LAN (`network.lan.dns`, например 1.1.1.1) сохраняется. Исправление касается отдельных параметров dnsmasq `server` и `noresolv`.
- Исправлена проверка платформы в обновляторе LuCI: поддерживаются OpenWrt 25.12.5 и 25.12.6 / aarch64. Проверки архитектуры, манифеста, размера и SHA-256 APK сохранены.
- Ошибка проверки TTL показывает протокол, порт, полученное и ожидаемое значения.
- Сохранены прямое обновление подписки и изоляция недоступных нод из 1.4.3.

На Dimarouternew проверены применение DNS и TTL 60 по UDP/TCP. На LAB проверены остановка с сохранением прямого DNS/HTTPS, повторный запуск, перезагрузка и чистый запуск без ручного обновления подписки. Watchdog перешёл в healthy, основной маршрут вернул HTTP 204, NetBird сохранил подключение.

Обновление APK сохраняет настройки. Отдельные DNS- и version-hotfix из 1.4.3 входят в этот пакет; повторно применять их после обновления до 1.4.4 не требуется. Если старый обновлятор на 25.12.6 отказывает до скачивания, сначала примените scripts/fix-package-openwrt-25126.sh или установите проверенный APK локально. Ядро Xray и NetBird управляются отдельно; обновлять сервер бота для этих исправлений не требуется.

Известное ограничение: применение настроек DNS при остановленном Xray остаётся отдельной задачей. Причина проблем Instagram не установлена этим исправлением. Подробности: docs/dns-forwarding-isolation.md.
