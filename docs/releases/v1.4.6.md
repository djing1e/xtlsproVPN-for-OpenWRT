# xtlsproVPN 1.4.6-r1

- В Настройки → Память добавлено управление ZRAM: установка пакета zram-swap из репозитория OpenWrt, включение/отключение и автозапуск, размер и поддерживаемые ядром алгоритмы сжатия.
- Показываются объём и доступная RAM, активный размер ZRAM, занятый swap, алгоритм, приоритет и результат операции. Чтение страницы ничего не устанавливает и не меняет.
- Предложен проверенный на Dimarouternew и Lushnikov профиль: 128 МиБ, lzo, приоритет 100. Существующие ручные настройки читаются из system UCI; подключённый вручную ZRAM определяется автоматически.
- Настройки применяются отдельной фоновой операцией под общей блокировкой приложения. Установка пакета использует IPv4. Недопустимые размеры и алгоритмы отклоняются на сервере.
- Перед отключением или перезапуском активного ZRAM требуется свободная RAM не менее занятого swap плюс 32 МиБ. При нехватке памяти операция отклоняется до изменения настроек. При сбое применения прежние поля system восстанавливаются; другие системные настройки сохраняются. Во время отката активный swap принудительно не отключается; фактическое состояние видно в панели.
- Открытие UI и обновление APK не устанавливают и не включают ZRAM автоматически. Включение — только по явному действию администратора. Xray и NetBird для этого не перезапускаются.

Сохранены исправления DNS/TTL, обновлятора OpenWrt 25.12.6 и совместимости dnsmasq/NetBird. Сервер бота обновлять не требуется.

На Lushnikov/OpenWrt 25.12.6 профиль 128 МиБ lzo подтверждён по /proc/swaps (131068 KiB, priority 100) и /sys/block/zram0/comp_algorithm. Применение через новую UI ещё требует аппаратной проверки после обновления APK.

Известное ограничение: применение настроек DNS при остановленном Xray остаётся отдельной задачей.
