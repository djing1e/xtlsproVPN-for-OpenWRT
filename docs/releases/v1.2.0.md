# xtlsproVPN v1.2.0 (r3)

Переключение серверов через API Xray, управление обновлениями NetBird и скрытие сохранённой ссылки подписки в интерфейсе.

- Ручной выбор сервера и возврат в автовыбор применяются через API без перезапуска Xray. Уже установленные соединения остаются на прежнем узле; новые используют выбранный. Сохранение соединений при недоступности прежнего узла не гарантируется.
- Сохранённая ссылка подписки не возвращается новым RPC и не отображается в форме. Пустое поле сохраняет прежнюю ссылку. Это защита от копирования через форму, а не от root-администратора: запрет раздачи требует ограничений на сервере подписок.
- Статус подключённого NetBird выделен зелёным. В UI добавлены проверка и установка обновлений из подписанного репозитория OpenWrt. Версия в нём может отставать от GitHub. Обновление NetBird кратковременно прерывает административный доступ.
- Добавлена ограниченная история смен узла и PID в RAM для диагностики фоновых обрывов.
- Исправлены запрос каталога NetBird для APK 3, применение сгенерированной конфигурации при обновлении приложения и исполняемые права init-скрипта. Упаковка явно устанавливает права; проверка исходников выявляет их потерю до сборки.

На LAB Cudy WR3000U v1 / OpenWrt 25.12.5 проверены установка r3, ручная смена сервера без смены PID и наблюдаемого разрыва загрузки, HTTPS 204, DNS UDP/TCP TTL 60 и сохранение подключения NetBird. Применение изменённой конфигурации подписки перезапустило Xray; повторная синхронизация неизменной подписки сохранила PID. Причина ранее наблюдавшегося фонового обрыва не установлена. Фактическая установка новой версии NetBird пока не проверена: репозиторий предлагает уже установленную версию.

Пакет: **xtlsprovpn-1.2.0-r3.apk**, OpenWrt 25.12.5 / aarch64. Ядро Xray и NetBird управляются отдельно. Настройки при обновлении сохраняются. В релиз включены APK, SHA256SUMS и update.json для обновления через LuCI.

## Установка и обновление

Чистая установка:

```sh
wget -O /tmp/xtls-install.sh https://raw.githubusercontent.com/djing1e/xtlsproVPN-for-OpenWRT/main/install.sh && sh /tmp/xtls-install.sh
```

Обновление установленного приложения:

```sh
wget -O /tmp/xtls-update.sh https://raw.githubusercontent.com/djing1e/xtlsproVPN-for-OpenWRT/main/update.sh && sh /tmp/xtls-update.sh
```

Либо Services → xtlsproVPN → обновление приложения → проверить обновления → установить.
