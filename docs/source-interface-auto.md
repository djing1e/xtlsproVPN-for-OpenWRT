# Автоматическое определение интерфейса источника

В разделе «DNS и сеть» пустой выбор «Сетевые интерфейсы источника» означает автоматический выбор устройства логического интерфейса `lan` из текущего состояния OpenWrt netifd. Обычно это `br-lan`; имя моста не зашито в коде. Обнаруженный интерфейс показывается под полем выбора.

При генерации конфигурации и правил nftables используется один и тот же список. Сохранённый старый `lab_iface` больше не перекрывает текущее устройство LAN. Во время запуска netifd или при недоступности ubus допускается сохранённый интерфейс профиля. Если определить интерфейс и использовать профиль невозможно, выводится предложение выбрать источник вручную.

Ручной выбор имеет приоритет и поддерживает несколько устройств. Дополнительные клиентские сети и гостевые VLAN следует добавить вручную. WAN, VPN и интерфейсы удалённого управления автоматически в источники не включаются. Маршрут по умолчанию не используется для определения источника: в режиме точки доступа он может проходить через тот же LAN-мост.

Ветка также включает ранее подготовленные исправления карточки бота (версия из базы APK) и сравнения конфигурации при регистрации (неявное `rich_messages: true` не считается изменением файла). Проверки действительных изменений конфигурации сохраняются.

Изменения исходников не обновляют установленные APK или сервер бота. Для распространения требуется сборка и установка обновлённого пакета; серверная часть обновляется отдельно. Логика выбора локаций не изменена.
